# 株の予測帳

テクニカル指標の計算式だけで、株が上がるか下がるかを予測するスマホ向けアプリです。学習（AI）は使いません。

- GitHub Actions が yfinance で最新の株価を取り、画面を作り直して公開します（日本株は平日16時40分ごろ、米国株は日本時間の朝7時ごろ）
- 5つのルールの重みは、過去の株価で243通りを全部試して自動で決めます
- 銘柄ごとに、株価や予測を入れた「AIに聞く文章」をテンプレートから作れます（コピーして Claude や ChatGPT に貼り付け）
- スマホのホーム画面に置くと、アプリのように開けます

費用は0円です（GitHub の公開リポジトリなら Actions と Pages は無料）。

## はじめの設定（1回だけ・10分ほど）

1. GitHub で新しいリポジトリを **Public** で作る（無料プランでは、Pages は公開リポジトリでしか使えません）
2. このフォルダの中身をすべて push する
   ```
   git init
   git add .
   git commit -m "最初のコミット"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** にする
4. **Actions** タブで「株価を更新して公開」を選び、**Run workflow** を押す（初回だけ手で動かす）
5. 1〜2分で終わると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます
6. スマホの Safari で開き、共有ボタン →「ホーム画面に追加」

あとは何もしなくても、平日は毎日株価が新しくなります。

## 銘柄を増やす・減らす

`tickers.json` を書きかえて push するだけです。push すると自動で取り直して公開します。

```json
{ "code": "6758.T", "name": "ソニーグループ" }
```

日本株は証券コードの後ろに `.T`、米国株はティッカーそのまま（`AAPL` など）、日経平均は `^N225`、S&P500 は `^GSPC` です。

単位（円・ドル・ポイント）はコードの形から自動で決まります。違うときは `"unit": "ドル"` のように書き足してください。テンプレートでは `{{単位}}` で使えます。

## AIに聞く文章

「AIに聞く」タブで、テンプレートを選ぶと、その銘柄のデータが入った文章ができます。コピーして AI に貼り付けてください。

- テンプレートは「買うか判断」「短期の売買タイミング」「長く持つか」の3つ。追加・編集できます
- `{{終値}}` のように書いた部分に、その銘柄のデータが入ります（編集画面のボタンで入れられます）
- 銘柄ごとに、使うテンプレートとメモ（予算・持っているかなど）を覚えます
- テンプレートとメモは、その端末のブラウザにだけ保存されます（リポジトリには入りません）

## ファイル

| ファイル | 役目 |
|---|---|
| `site/index.html` | 画面と計算のすべて |
| `site/sw.js`・`site/manifest.webmanifest`・`site/icon-*.png` | ホーム画面に置くため |
| `fetch.py` | 株価を取って `site/data/` に保存する |
| `tickers.json` | 取る銘柄の一覧 |
| `.github/workflows/update.yml` | 毎日の自動実行と公開 |

手元で試すときは `pip install yfinance` → `python fetch.py` → `cd site && python -m http.server` で `http://localhost:8000` を開きます。

## 知っておくこと

- yfinance は Yahoo Finance の非公式の取り出し口です。仕様が変わって取れなくなることがあります。そのときは Actions のログに「失敗」と出て、画面は前回のデータのままになります。`pip install -U yfinance` で直ることが多いです
- 公開リポジトリなので、コードと株価のデータは誰でも見られます。URL を知っている人は画面も開けます。Yahoo のデータを広く配る形にはしないでください（自分で使う範囲にとどめる）
- GitHub は60日間なにも変更がないと定期実行を止めますが、この仕組みでは毎日株価をコミットするので止まりません
- 予測は学習用の目安です。投資の判断を勧めるものではありません
